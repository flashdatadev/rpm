# FlashData RPM repository

[简体中文](README.zh-CN.md) · [FlashData](https://flashdata.dev) · [API docs](https://flashdata.dev/docs) · [CLI repository](https://github.com/flashdatadev/flashdata-cli)

Official signed RPM packages for the open-source FlashData CLI. FlashData provides structured Google Search and YouTube data; the CLI adds secure profiles, background jobs, bulk exports and recoverable runs. Packages preserve the released CLI executable bytes and include English/Chinese docs, examples, a manual and license notices.

The repository is being prepared. Full installation instructions will be added after native RPM signature verification and Fedora/RHEL installation tests. The stable URL is `https://flashdatadev.github.io/rpm/`.

Dedicated signing certificate: `23AB58683E85FE7236D369713D19EA52D181CC36` (`FlashData RPM Signing <support@flashdata.dev>`). Both RPM packages and repository metadata are signed with RSA-4096/SHA-256. The certification primary key is kept out of CI.
